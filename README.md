# 🏥 Hospital Performance & Revenue Analytics Dashboard

## 📌 Project Overview

The **Hospital Performance & Revenue Analytics Dashboard** is an interactive Business Intelligence project developed using Microsoft Power BI. The project focuses on analyzing healthcare data to understand hospital performance, patient admissions, revenue distribution, and operational trends.

The dashboard transforms raw healthcare datasets into meaningful visual insights through interactive KPIs, charts, and data visualizations.

The project consists of **three dashboard pages**, designed with a consistent healthcare-themed layout and a professional blue and teal colour palette.

## 🎯 Project Objectives

- Analyze overall hospital performance.
- Monitor patient admissions and healthcare activities.
- Evaluate hospital revenue and financial performance.
- Identify revenue distribution across different categories.
- Compare hospital performance using key indicators.
- Present complex healthcare data through interactive dashboards.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and data visualization.
- **Microsoft Excel** – Data inspection and preparation.
- **CSV Datasets** – Healthcare data sources.
- **DAX** – Calculated measures and KPI development.
- **GitHub** – Project documentation and version control.

## 📊 Dashboard Pages

### 1. Healthcare Overview Dashboard
Provides an overview of healthcare operations through key performance indicators and interactive visualizations.

### 2. Patient & Clinical Analytics Dashboard
Focuses on patient-related information, admissions, physician performance, and clinical insights.

### 3. Hospital Performance & Revenue Dashboard
Analyzes the financial and operational performance of hospitals.

**Key Performance Indicators (KPIs):**
- Total Revenue
- Total Patients
- Total Admissions
- Average Revenue per Patient
- Insurance Revenue
- Out-of-Pocket Revenue

**Visualizations:**
- Revenue by Hospital
- Monthly Revenue Trend
- Revenue by Diagnosis
- Hospital Performance Comparison
- Revenue Distribution by Payment Type

## 📁 Dataset Description

The project uses five healthcare CSV datasets:

| Dataset | Description |
|---|---|
| patients_2016_2026.csv | Patient and admission-related information |
| hospitals.csv | Hospital information |
| medications.csv | Medication records |
| procedures.csv | Medical procedure records |
| diagnosis_reference.csv | Diagnosis reference information |
